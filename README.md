## שלב 1 – בוט וערוץ בטלגרם
1. פתח את **@BotFather** ← שלח `/newbot` ← תן שם. תקבל **טוקן**, שמור אותו.
2. צור ערוץ חדש משלך, למשל `@my_rm_news`.
3. הוסף את הבוט לערוץ כ**מנהל** עם הרשאה לפרסם הודעות.

## שלב 2 – GitHub (שם הבוט רץ בחינם, גם כשהמחשב כבוי)
1. צור חשבון ב-github.com ← **New repository** ← בחר **Public**.
   > ⚠️ חייב להיות **Public**. ב-repo ציבורי GitHub Actions חינמי ללא הגבלה. ב-Private יש מכסה חודשית שהבוט יעבור.
   > הטוקן נשמר ב-Secrets ואף אחד לא רואה אותו. הקוד עצמו גלוי, וזה בסדר.
2. העלה את כל הקבצים: **Add file ← Upload files**.
   את התיקייה `.github/workflows` צריך ליצור ידנית: **Add file ← Create new file**, כתוב בשם
   `.github/workflows/bot.yml` והדבק את התוכן.
3. **Settings ← Secrets and variables ← Actions**:
   - לשונית **Secrets** ← New repository secret:
     - `BOT_TOKEN` = הטוקן
     - `TARGET_CHANNEL` = `@my_rm_news`
   - לשונית **Variables** ← New repository variable:
     - `SOURCE_CHANNELS` = `real_madrid, themadridzone, FabrizioRomanoTG:rm`
4. לשונית **Actions** ← אשר הפעלה ← בחר את ה-workflow ← **Run workflow**.

## שלב 3 – לתפוס בעלות על הבוט 🔐
**מיד** אחרי ההרצה הראשונה, שלח לבוט הודעה בפרטי (למשל `/settings`).
הראשון ששולח לבוט הודעה הופך לבעלים, וכל השאר נחסמים.
התפריט יופיע אחרי עד כ-5 דקות, בהרצה הבאה.

## ⚙️ שימוש
- `/settings` – תפריט כפתורים: הדלקה וכיבוי של כל נושא, מצב לילה, סיכום יומי וסינון שחקנים
- `/add Vinicius, Mbappe, Bellingham` – הוספת שחקנים לרשימה
- `/remove Mbappe` – הסרת שחקן
- `/players` – הרשימה שלך
- `/summary` – תצוגה מקדימה של הסיכום של היום

**🎯 סינון שחקנים:** כשהוא דולק, מגיעות רק ידיעות על השחקנים ברשימה.
הרכבים, תוצאות וחדשות מאמן ממשיכים להגיע תמיד, כי הם רלוונטיים לכל הקבוצה.
כדאי להוסיף כמה כתיבים של אותו שחקן, למשל `Vinicius, Vini`.

## ⏱ חשוב לדעת
- GitHub מריץ את הבוט כל 5 דקות בערך, ולפעמים מאחר ב-10–15 דקות. לכן גם ידיעות וגם לחיצות על כפתורים מגיעות באיחור קטן.
- הבוט שומר את ההגדרות בקובץ `state.json` ב-repo, ומעדכן אותו לבד. אל תמחק אותו.
- פוסט שהוא רק תמונה בלי טקסט מדולג, כי אי אפשר לדעת על מה הוא.

## 🛠 כיוונון (בקובץ `bot.py`)
- `CATEGORIES` – מילים שהופכות ידיעה לחשובה. מילה עם `*` תופסת גם המשכים: `injur*` תופס injury ו-injured.
- `IGNORE` – מילים שגורמות לדלג על ידיעה.
- `QUIET_START`, `QUIET_END`, `SUMMARY_HOUR` – שעות מצב הלילה ושעת הסיכום.
- `SIMILARITY` – רגישות זיהוי הכפילויות. אם עוברות כפילויות, הורד ל-0.4. אם נחסמות ידיעות שונות, העלה ל-0.6.
